# Expense Diary | Backend Project with Spring Boot

Expense Diary is a **backend project** made using **Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, JWT, Junit, Mockito and Flyway Migrations**.
> GitHub link for this app is [Expense Diary](https://github.com/soumyadip-cy/ExpenseDiary)

---

### Features

1. REST API endpoints using GET, POST, PATCH, and DELETE to perform operations.
2. DTOs for data protection.
3. JWT based authentication system using Spring Security.
4. MVC architecture with different layers for controller, service, repository, entities, etc.
5. Global exception handling using @RestControllerAdvice.
6. Database migration queries using Flyway migrations.
7. Mappers using MapStruct for easy mapping between DTOs and entities.
8. Role based authentication with 2 custom-made user roles.
9. Login and logout time audit logging.
10. Standardized response using ApiResponse and ApiMessage DTOs.
11. Standardized pagination and sorting using PageableUtil class.
12. Junit and Mockito based unit and integration tests.
13. Logging using SLF4J.
14. Package management using Gradle.
